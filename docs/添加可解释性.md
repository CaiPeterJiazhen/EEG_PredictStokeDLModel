============================================================
二、Attribution 方法
============================================================

Primary method:
Integrated Gradients

Secondary smoothing:
SmoothGrad / NoiseTunnel over Integrated Gradients

Validation methods:
1. Group occlusion
2. Feature permutation
3. Branch ablation
4. State ablation

Do not rely only on raw gradients.
Do not use Grad-CAM as the main method because we need input-level channel-frequency and edge-band attribution.
Do not use full SHAP over all 1891 x 6 WPLI features as main method because it is too expensive and unstable for n=19.

If Captum is available, use:
- IntegratedGradients
- NoiseTunnel
- FeatureAblation / Occlusion

If Captum is not available, implement manual integrated gradients:
- baseline = zero tensor after fold-local scaling
- steps = 64
- interpolate x = baseline + alpha * (input - baseline)
- accumulate gradients of classification logit
- attribution = (input - baseline) * mean_gradient

Target:
classification logit, not sigmoid probability.

If current model only returns probability:
add a method or option:
- return_logits=True
- forward_logits(batch)
- forward_with_aux(batch, return_logits=True)

============================================================
六、Occlusion validation
============================================================

Implement group occlusion.

PSD occlusion groups:
1. branch-level:
   - zero PSD branch
   - zero WPLI branch
2. state-level:
   - zero EO
   - zero EC
3. PSD band-level:
   - zero Delta / Theta / Alpha / Beta Low / Beta Medium / Beta High
4. PSD channel-level:
   - zero one channel at a time
5. PSD channel x band:
   - zero channel-band block

WPLI occlusion groups:
1. WPLI band-level:
   - zero all edges in one band
2. WPLI edge-level:
   - zero one edge x band, optionally top candidate edges only for efficiency
3. WPLI node-level:
   - zero all edges connected to one node
4. interhemispheric vs intrahemispheric edges
5. predefined network group edges

For each occlusion:
compute:
- delta_logit = original_logit - occluded_logit
- delta_probability = original_prob - occluded_prob
- delta_loss if y_true available

Save:
results/explainability/occlusion_branch_state.csv
results/explainability/occlusion_psd_band_channel.csv
results/explainability/occlusion_wpli_edge_node_band.csv

Use occlusion to validate IG:
Top IG features should have non-trivial occlusion effect.
If IG and occlusion disagree strongly, mark interpretation as unstable.

============================================================
七、Stability analysis
============================================================

Implement stability metrics:

1. top-k selection frequency across seeds
   k = 10, 20, 50

2. Spearman correlation of attribution maps between seeds

3. Jaccard similarity of top-k features between seeds

4. bootstrap CI over subjects for:
   - top PSD channel-band features
   - top WPLI edge-band features
   - branch occlusion effects
   - EO/EC gate weights

Output:
results/explainability/attribution_stability_summary.csv

Interpretation rule:
Only features with high selection frequency and stable attribution should be promoted as key biomarkers.

Default promotion criteria:
- appears in top-20 in at least 5 of 10 seeds, or
- bootstrap CI for abs attribution excludes near-zero threshold, or
- validated by occlusion effect in the same direction

============================================================
八、Sanity checks
============================================================

Implement at least two sanity checks:

1. Model randomization sanity check:
   - randomize classifier weights
   - recompute attribution for a small subset
   - attribution map should not remain strongly correlated with trained attribution

2. Input permutation sanity check:
   - permute PSD frequency bins or WPLI edge order
   - attribution should degrade or lose meaningful top features

Optional:
3. label-randomized model sanity check
   - only if cheap; otherwise document not run

Output:
results/explainability/sanity_check_summary.csv

Do not present attribution as reliable if sanity check fails.
