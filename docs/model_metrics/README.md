# Model Metrics Tables

This folder keeps Git-tracked CSV copies of the patient-level 10-seed model metrics used for manuscript figures and result reporting.

- `patient_level_model_scorecard_with_barlow.csv`: five-model scorecard source table for Logistic L1, No-SSL CNN, Barlow CNN, Residual-aware CNN, and Residual-aware SSL-CNN.
- `core_ablation_10seed_summary.csv`: source 10-seed summary table for the first four model rows in the scorecard.
- `final_Residual_ssl_cnn.csv`: locked final Residual_Barlow_CNN / Residual-aware SSL-CNN 10-seed result table.

The current locked final model result is `final_Residual_ssl_cnn.csv`, not the older `final_ssl_cnn.csv`.
