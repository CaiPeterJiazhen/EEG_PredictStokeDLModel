# Model Reporting Card

This table summarizes intended use, evidence boundaries, validation safeguards, deployment restrictions, and reproducibility actions for the current residual-aware SSL-CNN manuscript package. It is included as Supplementary Table 11 in the compiled Supplementary Information.

| Card section | Reporting item | Current value | Reviewer risk | Manuscript action |
|---|---|---|---|---|
| Intended use | Prediction task | Patient-level prediction of upper-limb proportional-recovery status after stroke using baseline resting-state EEG. | The model is internally validated only and should not be framed as deployable. | Report as an exploratory prognostic model requiring external validation. |
| Intended use | Clinical decision context | Candidate stratification support for rehabilitation-response research, not an approved clinical decision tool. | Overstating clinical readiness would exceed the evidence. | Retain the current prospective-validation and no-deployment wording. |
| Population | Supervised validation cohort | 19 stroke patients with baseline EEG and complete baseline/follow-up FMA-UE. | Small sample size limits precision, calibration, and generalizability. | State n=19 wherever performance is reported and avoid population-level claims. |
| Population | Unlabelled or non-supervised EEG pool | 28 EEG-indexed patients were available, with 9 outside supervised outcome modelling. | The additional EEG pool cannot substitute for labelled external validation. | Describe as self-supervised/descriptive support only. |
| Outcome | Endpoint definition | Label derived from residual = 0.7 x (66 - baseline FMA-UE) - observed FMA-UE change; threshold was cohort median residual 1.5. | Median-derived endpoint may not transport to future cohorts. | Call the threshold cohort-specific and require prospective pre-specification. |
| Predictors | Model inputs included | Baseline eyes-open and eyes-closed PSD plus WPLI features from preprocessed EEGLAB files. | Upstream acquisition and preprocessing details remain author-confirmed. | Keep the current feature-pipeline boundary explicit. |
| Predictors | Inputs excluded from EEG model | Post-treatment outcomes, observed improvement, predicted improvement, residuals, and labels were excluded from model inputs. | Outcome leakage would invalidate the model if not clearly excluded. | Retain explicit exclusion language in Methods. |
| Training | Architecture | Multimodal CNN with PSD and WPLI branches, gated 32-dimensional fusion, patient-level Barlow Twins pretraining, and residual-aware auxiliary heads. | Architecture claims must match reproducibility scripts. | Package code and exact commit hash before final submission. |
| Training | Residual-aware supervision | Fine-tuning combined binary classification with signed residual-distance and pairwise recovery-ranking objectives. | Ablations support this as exploratory training-signal evidence, not a universal mechanism. | Use 'ablation-supported in this dataset' rather than 'proved'. |
| Validation | Validation unit | Patient-level leave-one-subject-out validation; no segment-level or seed-level row was treated as an independent patient. | Segment-level leakage is a common EEG prognosis concern. | Keep patient-level validation safeguards prominent. |
| Validation | Uncertainty and comparisons | Subject-level bootstrap intervals, paired bootstrap comparisons, McNemar tests, permutation tests, and one-case resolution audit. | Intervals remain wide and paired superiority was not established. | Preserve conservative wording for favorable numerical differences. |
| Performance | Final internal performance | Accuracy 0.842, balanced accuracy 0.833, ROC-AUC 0.844, PR-AUC 0.836, and Brier score 0.126. | Point estimates can look stronger than warranted by n=19. | Report together with bootstrap intervals, precision audit, and no-external-validation caveat. |
| Performance | Clinical-only comparator boundary | Clinical-only baseline was strong in exploratory analyses; EEG incremental value over clinical variables was not established. | Claiming EEG clinical utility would be unsupported. | Frame EEG as candidate neurophysiological marker for prospective testing. |
| Explainability | Attribution interpretation | SmoothGrad-integrated-gradient, occlusion, topographic, and WPLI connectome summaries are model-dependent and hypothesis-generating. | Channel, frequency, or edge findings could be overread as causal biomarkers. | Retain model-dependent and associative interpretation. |
| Limitations | External validation | No independent external validation cohort is available in the current package. | External performance, calibration, and transportability are unknown. | Make prospective external validation the primary next step. |
| Limitations | Author-confirmed protocol metadata | Ethics, consent, recruitment, EEG acquisition, upstream preprocessing, tACS device/electrode/safety, rehabilitation co-intervention, and repository metadata remain incomplete. | Final submission cannot be considered complete until these fields are author-approved. | Use the author metadata workbook before final insertion. |
| Availability | Shareable derived evidence | Derived tables, locked predictions/statistics, figure exports, audit tables, source-data workbook, and scripts can be deposited after author approval. | No repository DOI or licence has been assigned yet. | Deposit final derived-data and code package with DOI before journal upload or publication. |
| Availability | Restricted source evidence | Raw EEG, minimally processed EEG, and clinical source records require ethics, consent, privacy, and data-use review. | A vague 'available upon request' statement would be weak without restriction rationale and access route. | Specify controlled-access route, contact, review criteria, and data-use agreement once author information is available. |
| Use restrictions | Unsupported uses | Do not use the model for individual treatment allocation, standalone prognosis, or clinical deployment without external validation and governance approval. | Clinical-deployment language would conflict with the current evidence. | Keep the final conclusion limited to feasibility and prospective validation. |

## Summary

- The model is ready for transparent exploratory reporting, not clinical deployment.
- The strongest current safeguards are patient-level LOSO validation, fold-local feature handling, subject-level statistical comparisons, and explicit claim-strength boundaries.
- Remaining blockers are author-approved ethics, consent, recruitment, EEG acquisition/preprocessing, intervention/safety, data-access, and repository metadata.
