## Fixed Decisions

- Use the 19 subjects in `F:\CJZFile\EEG_M1\19例患者脑电数据完整性检查.xlsx` as the supervised cohort.
- Use actual 62 EEG channels, not 64.
- Deleted channels are `M1` and `M2`.
- `*1.set` is EO.
- `*2.set` is EC.
- Main supervised EEG input uses baseline patient EEG only.
- Label threshold is residual median `1.5`.
- Positive label uses `Residual <= 1.5`.
- Patient-level LOSO-CV is mandatory.
- Four `.set` files have stale internal `.fdt` names caused by post-processing renames; the confirmed companion mappings are `zqc1.fdt -> zqz1.fdt`, `dqm1.fdt -> sqm1.fdt`, `cyq1.fdt -> zyq1.fdt`, and `ccx.fdt -> ccx1.fdt`.
- SSL data scopes are `supervised-baseline`, `all-patient-baseline`, `all-patient`, `all-patient-health`, and optional `health-only`. In strict LOSO SSL mode, the current test patient is excluded from any patient-containing SSL pool.
- Feature-space SSL transfer into the current PSD/FC CNN uses fold-local pretraining. For healthy EEG, feature computation uses the no-flip convention equivalent to affected hand `右`.
- Structured TFR SSL also applies affected-hand hemisphere alignment before STFT so its channel coordinate system matches PSD/FC feature extraction.
- Masked PSD/FC SSL transfers only branch encoder weights; reconstruction decoders are discarded before supervised LOSO fine-tuning. The current masked SSL implementation uses pre-pooling local reconstruction from CNN feature maps.
- Multi-task masked+alignment SSL is enabled through `scripts/09_train_masked_ssl_transfer.py --contrastive-weight > 0`. `--alignment-method ntxent` uses in-batch negatives. `--alignment-method vicreg`, `barlow`, and `byol` are no-negative alternatives. The best current completed single-seed NT-Xent setting uses `contrastive_weight=0.01`; the best current no-negative setting is VICReg `contrastive_weight=0.001`, `invariance=25`, `variance=25`, `covariance=1`.
- Saved SSL LOSO prediction ensembling and threshold calibration are run with `scripts/10_ensemble_ssl_predictions.py`. Current NT-Xent+VICReg seed2 equal-weight and OOF-calibrated ensembles did not improve over the single NT-Xent seed2 model.
- Multi-task NT-Xent SSL multi-seed stability has been checked on seeds `0,1,2,3,7,13`. Compared with the same no-SSL seeds, SSL improved mean accuracy from `0.6930` to `0.7281` and reduced accuracy std from `0.1173` to `0.0843`, but did not exceed the best single-seed accuracy `0.8421`.
- Multi-task VICReg SSL multi-seed stability has been checked on the same seeds with `contrastive_weight=0.001`, `inv=25`, `var=25`, `cov=1`. VICReg improved mean accuracy to `0.7544` and reduced accuracy std to `0.0430`, making it the most stable SSL variant tested so far.
- No-SSL CNN stability scheme A has been checked. The recommended stable supervised protocol is `lr=0.002`, `weight_decay=0.00001`, `dropout=0`, which improved mean accuracy from `0.6930` to `0.7193`, minimum seed accuracy from `0.5263` to `0.5789`, and accuracy std from `0.1173` to `0.1035`.
